# King Kong boxing guardian art

Portrait generated with the built-in `image_gen` tool (imagegen skill), saved
as `demo/features/characters/kingkong/portrait-art.png`. It is new art, with
no input-image edits and an opaque background. The original generation is
preserved; this feature folder contains the project-owned copy.

The playable model is independently authored in Blender by
`tools/characters/build_kingkong.py`, using the same rig and palette approach
as the Dragon Knight. Editable scene:
`Assets/Art/Blender/Characters/KingKongGuardian.blend`. Runtime meshes and
pivots: `demo/features/characters/kingkong/model.js`; runtime assembler:
`demo/features/characters/kingkong/kingkong.js`.
